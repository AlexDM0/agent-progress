# 002 — Orders CSV export

## Report

Finance copies orders out of the admin by hand every month-end, page by page.

## Wanted

An "Export CSV" button on the orders list that downloads the rows matching the current filters.

## Acceptance

- The export holds exactly the rows the filtered list holds, across all pages.
- Columns: order number, date, customer e-mail, items, subtotal, tax, total, status.
- An export of 20,000 orders streams and finishes in under 10 seconds locally.

## Brief

Work belongs in: `src/admin/orders/`, `src/admin/export/` (new).

Out of bounds regardless: `src/checkout/` — #001 is working there.

Facts you do not need to look up:

1. The list's filters serialise to a query string through `OrderFilter.toQuery`.
2. `db.orders.stream(query)` already exists and yields rows in id order.

Fails review if false: row counts match for three filter combinations; the 20,000-row timing.
