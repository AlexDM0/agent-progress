# 010 — Stale basket badge

## Report

A guest adds two items, signs in to an account that already had one in its basket, and the header
badge says 2 while the basket page lists 3.

## Wanted

The badge shows the merged count as soon as sign-in completes, without a reload.

## Acceptance

- The scenario above shows 3 in the badge within one second of sign-in.
- No extra request per page view: the count comes from the sign-in response.

## Brief

Work belongs in: `src/basket/BasketBadge.tsx`, `src/auth/SignIn.ts`.

Fails review if false: the badge count in a browser run of the scenario, with a screenshot.
