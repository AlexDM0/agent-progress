# 008 — Rate-limit resets

## Report

The reset endpoint answered 3,200 requests for one e-mail address in ten minutes last night. Each one
sent a mail.

## Wanted

At most 5 reset requests per address per hour and 30 per IP per hour; the sixth is answered like the
first, so the limit reveals nothing about which addresses exist.

## Acceptance

- The sixth request within an hour sends no mail and returns the same 202 and body as the first.
- Limits survive a restart (they live in the existing Redis, not in memory).
- A load test of 1,000 requests shows 5 mails sent.
