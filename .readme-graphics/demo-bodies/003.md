# 003 — Accent-blind search

## Report

Searching "creme" finds nothing, although the shop sells "Crème brûlée kit" and "Crème fraîche jar".

## Wanted

Search matches regardless of accents and case, in both directions: "creme" finds "Crème", and "crème"
finds "Creme".

## Acceptance

- "creme", "Creme" and "crème" return the same two products.
- Existing ranking specs still pass unchanged.
- The index rebuild for 12,000 products stays under 30 seconds.
