# 011 — Saved payment methods

## Report

Returning customers type their card in again on every order.

## Wanted

A signed-in customer can save a card at checkout and pick it next time.

## Acceptance

A1. A saved card shows its brand and last four digits only.
A2. Saving needs a fresh sign-in, rate-limited as #008 limits password resets.
